# Deep-SANE

**Deep**-learning & **S**ymmetry-adapted, **A**b-initio **N**uclear modeling —
an AI-ready **E**cosystem.

A family of libraries for symmetry-adapted, ab-initio nuclear simulations, and deep learning for nuclear physics:

- **u3lib** — an AI-ready library for U(3) symmetry algebra, Wigner coupling & Racah recoupling coefficients
- **u4lib** — an AI-ready library for U(4) symmetry algebra, Wigner coupling & Racah recoupling coefficients
- **untou3** - an AI-ready library for U(N)->U(3) reduction for the nuclear shell model
- **SAM** — compute structure of nuclei from first principles using U(3) and U(4) symmetries in the nuclear shell model
